# Lanternfall

A small lantern-keeping adventure from Hollowpine Games. You walk the fog-bound
village of Greywick at dusk, relight the lamps, and talk to the people who
live there. Built in Godot 4.

Release plan: Steam next week, itch.io the week after.

## Layout

- `data/npcs.json`: the village cast
- `data/quests.json`: quest steps, flags and rewards
- `assets/`: portraits and voice lines (see `assets/MANIFEST.md`)
- `store/`: Steam page text, Steam content survey answers, itch.io page
